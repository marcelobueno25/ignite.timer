# Ignite Timer ⏱️

Este é um projeto de cronômetro de ciclos focado em produtividade, desenvolvido com **React**, **TypeScript** e utilizando conceitos avançados de **React Hook Form**, **Context API**, **Styled Components** e gerenciamento de estado.

🚀 Deploy: [ignite-timer.vercel.app](https://ignite-timer-eta-roan.vercel.app/)

## ✨ Funcionalidades

- Criar ciclos de foco com nome da tarefa e tempo determinado
- Contagem regressiva em tempo real
- Histórico de ciclos finalizados, interrompidos ou em andamento
- Validação de formulários com `zod` e `react-hook-form`
- Gerenciamento global com `Context API`
- Armazenamento dos ciclos ativos mesmo após atualizar a página (localStorage)
